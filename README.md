# Software Asset Management Application

## Overview
The Software Asset Management (SAM) application helps organizations manage their software assets effectively throughout their lifecycle, ensuring compliance, optimization, and cost management.

## Features
- **Asset Tracking:** Complete visibility of all software assets.
- **License Management:** Keep track of software licenses to ensure compliance.
- **Usage Monitoring:** Analyze usage trends to optimize software investments.
- **Reporting:** Generate reports for audits and analysis.

## Setup Instructions
### Prerequisites
- Ensure you have the following installed:
  - Node.js (version 14 or higher)
  - NPM (Node Package Manager)
  - Git

### Installation Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/korapraveen/simple-sam-app.git
   cd simple-sam-app
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Configure environment variables:
   - Create a `.env` file in the root directory using `.env.example` as a template.
4. Start the application:
   ```bash
   npm start
   ```

## Usage
- Access the SAM application through your browser at [http://localhost:3000](http://localhost:3000).
- Log in with your credentials.
- Navigate the features through the intuitive user interface.
